# CodeScan

Code analysis tool with Neo4j integration for code relationship mapping.

## Tools

- **scan_repository** - Scan and analyze a codebase
- **find_relations** - Find function/class relations
- **get_file_changes** - Get file change history
- **label_example_functions** - Label example/test functions
- **find_class_relations** - Find class relationships
