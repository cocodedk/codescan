تحلیلگر استاتیک پایتون با یکپارچه‌سازی Neo4j

پایتون Neo4j تجزیه AST سرور MCP Cursor IDE
ساخته شده توسط بابک بندپی  |  توسعه داده شده توسط Cocode  |  GitHub  |  English

ویژگی‌ها

  • تجزیه مبتنی بر AST: از ماژول ast پایتون برای پیمایش و تحلیل فایل‌های کد منبع استفاده می‌کند.
  • استخراج کلاس و تابع: تمام کلاس‌ها، توابع مستقل و متدهای کلاس را شناسایی می‌کند.
  • ساخت گراف فراخوانی: فراخوانی‌های تابعی را شناسایی کرده و روابط CALLS در گراف ایجاد می‌کند.
  • تشخیص تست و پوشش: مؤلفه‌های تست را شناسایی کرده و روابط پوشش تست برقرار می‌کند.
  • پیکربندی محیطی: تنظیمات اتصال Neo4j و پروژه را از فایل .env می‌خواند.
  • سرور MCP: ابزارهای پرس‌وجوی گراف را از طریق پروتکل Model Context برای Cursor IDE ارائه می‌دهد.
